# DeepTranslate 全文翻译

Chrome / Edge 扩展：保留原文，在每段下方显示 AI 译文（中英对照）。翻译引擎是你自己的大模型 API（需兼容 OpenAI `chat/completions` 接口）。

## 安装
1. 下载并解压 zip。
2. 浏览器打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的文件夹。

## 配置（首次使用必做）
点击工具栏图标 →「更多设置」，填写：
- **Base URL**：接口地址，如 `https://api.openai.com/v1`
- **API Key**：你自己的密钥（只保存在本机浏览器，不会上传到别处）
- **Model**：模型名

也可以把这三项写进一个 `secret.properties` 文件（见 `secret.properties.example`），在设置页点「选择文件」导入。填完点「测试连接」确认可用。

## 使用
- **Alt+A**：全文翻译 / 还原（快捷键可在弹窗里点「修改」调整）
- **选中文字后 Alt+A**：只翻译所在段落，再按一次取消
- 点击工具栏图标：选择目标语言、我的语言（已是该语言的文本不翻译）
- 只翻译屏幕附近的内容，滚动时继续翻译；失败的段落点击红字可重试
- 译文自动缓存，重复访问不再消耗额度

## 隐私
网页文字会发送到你在设置里填写的 API 地址进行翻译，除此之外不会发送到任何其他服务器。
